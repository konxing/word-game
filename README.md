# 打字小站 · 面向电脑零基础成人的离线打字游戏

**不用安装 · 不用注册 · 不用网络 · 不用运行服务器。**

专为刚开始接触电脑、尤其不熟悉键盘的成人设计。目标是先建立键盘位置感和输入信心，再逐步学会字母、拼音和中文输入，而不是一上来追求每分钟打多少字。

## Windows 使用方法

1. 在 GitHub 代码页点击 **Code → Download ZIP**，把压缩包解压。
2. 双击 **`开始练习.cmd`**，或直接双击 **`index.html`**。
3. 用 Microsoft Edge / Google Chrome 打开后，点击“开始第一关”。
4. 按屏幕高亮的键练习。错了继续试，不倒扣，不倒计时。
5. 到“中文输入”关卡时，点击输入框，使用 Windows 自带中文拼音输入法输入汉字。通常可按 **Windows 徽标键 + 空格键** 切换输入法，具体取决于 Windows 设置。

只用来练拼音的第 11、12 关，应保持 **英文输入状态**；中文输入第 13—16 关，应切换到**中文拼音输入状态**。

> 如果电脑没有安装中文拼音输入法：可以先完成第 1—12 关。中文输入需要操作系统内置或已安装的输入法，游戏本身不包含输入法。

## 功能

- 共 16 关，分“认识键盘 → 拼音与字母 → 中文输入”三个阶段；随时可以重复练习。
- 键盘高亮、F/J 摸键定位、手指建议、实时提示；默认不计时，不设置失败条件。
- Windows 拼音输入法的中文选字与改字，兼容输入法组合输入（IME composition）。
- 每关的完成记录、最高评价、完成关数、练习天数，保存到当前浏览器本地 `localStorage`。
- 放大字体、可选简单提示音、键盘操作支持；无广告、无统计脚本、无外部字体或网络请求。

## 离线保存说明

- 记录只在**同一台电脑、同一个浏览器的相同打开位置**下保存。换浏览器、移动文件夹、使用无痕模式或清除浏览器站点数据可能导致记录丢失。
- 如果浏览器禁用本地存储，仍能练习，但进度未必能在关闭后保存。
- 输入的中文练习内容不会上传任何地方；游戏没有服务器。

## 技术与开发

纯原生 HTML + CSS + JavaScript。所有依赖均随源码提供。直接用 `file://` 打开，无需 Node、Python 或 Web 服务。

开发者若安装了 Node.js 18+，可以运行：

```bash
node --test tests/*.test.cjs
```

主要文件：`index.html`（页面）、`styles.css`（样式）、`lessons.js`（关卡数据）、`engine.js`（纯计算逻辑）、`app.js`（练习界面与存档）、`tests/`（离线测试）。

## 设计准则

1. 大字体、大按钮；配色成熟、信息量低，不把成人当儿童。
2. 每一步只提示当前需要做的事；练错后给清晰纠错信息，不嘲讽、不催促。
3. 不把打字速度当首要评价指标。允许重复练习，给学习者明确的完成感。
4. 全部逻辑和资源本地化，断开网络仍可使用。
