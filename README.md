# 打字小站 · Word Game

面向不熟悉电脑键盘的成年人。**纯离线、免费、无账号、无广告**。默认练习很短：一次只练 6 个按键，或一个拼音词/一句中文。不要求速度，不设置失败倒计时。

## 最简单的启动方式：真正的 Windows EXE（推荐）

直接下载 **`打字小站.exe`** 到电脑，双击即可启动；不需要安装 Node.js、Python 或其他运行环境。右键 EXE → **发送到 → 桌面快捷方式**，以后直接双击桌面图标。

- 支持 Windows 10/11 **64 位**；启动器是 Go 编译的真正 PE Windows GUI 可执行文件，不是改名脚本；不会弹出命令行黑窗口。
- EXE 内嵌全部网页游戏资源。首次启动会自动解压到 `%LOCALAPPDATA%\TypingHarbor\App`，以后启动会更新程序资源，**不会清理存档**。
- 会使用电脑已安装的 Microsoft Edge 或 Google Chrome 以独立窗口打开本地游戏；**无需联网，但电脑需要有 Edge/Chrome**。这不是用 Electron 打包的全套浏览器，因此程序体积很小。
- 与旧版“安装到桌面.cmd”使用**相同的本地路径和专用浏览器资料目录** `%LOCALAPPDATA%\TypingHarbor\BrowserProfile`，正常升级可继续使用旧进度。曾直接在普通浏览器打开 `index.html` 的进度与专用资料目录不一定共享。
- 本地编译：安装 Go 1.23+ 后运行 `GOOS=windows GOARCH=amd64 go build -ldflags="-s -w -H windowsgui" -o dist/打字小站.exe .`（Linux/macOS shell）；Windows PowerShell 可直接运行 `go build -ldflags="-s -w -H windowsgui" -o 'dist/打字小站.exe' .`。
- GitHub 的 Actions → **Build offline Windows EXE** 自动构建并提供可下载的 EXE Artifact；仓库里的 Go 源码可以复现构建。构建产物 Windows 实机仍需最终验收。

## 推荐安装方式：桌面图标双击运行（Windows 10 / 11）

1. 在 [GitHub 仓库](https://github.com/konxing/word-game) 点击 **Code → Download ZIP**，并把压缩包 **先解压**，不要直接在压缩包中运行。
2. **第一次**：打开解压后的文件夹，双击 **`安装到桌面.cmd`**。
3. 安装程序把游戏复制到当前 Windows 用户的 `%LOCALAPPDATA%\TypingHarbor\App`，并在当前用户桌面创建 **「打字小站」快捷方式**。首次安装后会尝试自动打开游戏。
4. **以后**：直接双击桌面 **「打字小站」** 图标。会以独立应用窗口打开（不显示普通浏览器的标签栏、地址栏）。

此方式使用电脑上**已安装的 Microsoft Edge**（优先）或 **Chrome** 作为离线运行引擎；它是无框架的浏览器应用窗口和 Windows `.lnk` 快捷方式，**不是独立原生 `.exe`**。不需要 Node、Python、管理员权限、联网或额外下载软件（但电脑必须已有 Edge/Chrome）。

- 游戏文件安装路径固定，更新可以再次运行新版本压缩包中的 `安装到桌面.cmd`，会覆盖程序文件、保留浏览器资料目录。
- 快捷方式在第一次创建后就可独立使用，原来解压的 ZIP/文件夹可以删除。
- 进度只保存在这个电脑上的专用浏览器资料目录中：`%LOCALAPPDATA%\TypingHarbor\BrowserProfile`。不要随意删除这个目录，否则练习记录可能丢失。
- 如果之前用旧版 `index.html` 在浏览器里练过，旧的浏览器本地记录**不能自动迁移**到专用程序窗口；首次使用桌面版将从零开始。
- 如果系统的快捷方式被安全软件拦截，仍可以双击 `开始练习.cmd` 或 `index.html` 在浏览器中运行，但该方式和桌面版的记录**不一定相通**。
- 如果安装脚本因设备管理策略不允许运行，请交给熟悉电脑的人操作；无需关闭系统防病毒功能。

## 开始练习

打开游戏 → 点击大按钮“开始轻松练习” → 看屏幕上亮起的键 → 用真实键盘按下。

游戏遵循渐进原则：

- **认识键盘**：先从 F/J 两个键开始，逐步扩展到左右手、数字、空格、回车。
- **常用拼音**：输入 `ba`、`ma`、`jia` 等熟悉的拼音，不要求懂英语。
- **中文输入**：用 Windows 里已装的拼音输入法，输入“你好”等短句；通常 `Win + 空格` 可切换输入法。

默认首页只显示当前附近 4 关，需要时点击“查看全部 22 关”。默认一次只做一小段，完成后自愿选择“再练一小段 / 想多练一点（完整关） / 下一关”。系统会根据本地记录推荐未练习的课程，也会在距离上次练习至少两天后推荐简短复习。

错误不会扣除通关资格；多次按错同一键时提示会更加具体。完成评价以“完成了一小段”而不是速度或排行榜为主；想看正确率可自行展开详情。不设置连续签到惩罚。

## 技术和离线隐私

- 前端：HTML + CSS + JavaScript，所有题库均在 `lessons.js` 本地。
- 存储：浏览器 `localStorage`；练习内容不会发往服务器，无统计 SDK 和外部资源请求。
- 桌面安装：`windows/install.ps1` 将静态文件复制到当前用户目录，利用 `WScript.Shell` 创建 `.lnk`，Edge/Chrome 的 `--app` 参数打开本地 HTML 文件。
- 卸载：删除桌面“打字小站”快捷方式，然后按需删除 `%LOCALAPPDATA%\TypingHarbor`（删除该目录也会删除练习进度）。
- 直接运行：`开始练习.cmd` 或 `index.html`；适合不希望安装快捷方式的用户。

开发者测试（Node.js 18+）：

```bash
node --test tests/*.test.cjs
```

## 为什么这样设计？

《[学习心理学设计说明](docs/LEARNING-DESIGN.md)》记录了依据、实际对应的功能和限制。核心是**小步练习、即时且不责备的反馈、尊重自主选择、适度间隔复习、生活化的内容**。这是一套有研究依据的设计假设，**尚未针对这款游戏做中年成人的正式用户研究或效果实验**。

## 单屏专注练习与拼音提示

- 进入练习时自动隐藏侧边选关和统计栏，专注显示练习内容。常见桌面高度下不要求滚动整个页面；极小窗口或放大显示时练习卡片仍可内部滚动，避免截断。
- 第 13–22 关把拼音音节显示在**对应汉字正上方**，并跟随正确输入逐字高亮。后 6 关增加家庭问候、购物问路、聊天和生活记录等实际用途。
- 首次轻松模式仅输入一句，结算后可选择完整练习。原本的进度保留。
