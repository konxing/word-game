《打字小站》使用方法（Windows 电脑）

1. 将下载的 ZIP 压缩包解压到一个文件夹。
2. 双击文件夹里的“开始练习.cmd”，或者直接双击“index.html”。
3. 等浏览器打开页面，点击绿色的“开始第一关”。
4. 按屏幕上提示的字母键；按错可以直接重试，没有时间限制。
5. 学习中文输入时，先在输入框里点击一下，再切换到电脑自带的中文拼音输入法。
   常用切换方法：按住 Windows 徽标键，再按空格键。

注意：
- 不用安装、不用注册、不用联网、不用运行服务器。
- 练习记录保存在当前电脑的当前浏览器里。不要随便清理浏览器的站点数据。
- 建议使用 Windows 上的 Microsoft Edge 或 Google Chrome。
- 打字时请使用真实键盘，屏幕上的键盘图只负责提示位置。
