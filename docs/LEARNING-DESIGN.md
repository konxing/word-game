# 面向电脑零基础成年人的学习体验设计

本项目重心不是不断添加玩法或速度排行，而是帮助电脑初学者逐步形成键盘位置感，获得可以自己完成任务的体验。

| 理论或证据 | 本项目的对应设计 | 不应该做的过度推断 |
| --- | --- | --- |
| 自我决定理论：能力感、选择自主性和良好的支持环境有助于自主学习动机。Ryan & Deci（2020） | 默认短关卡；显示具体进度；可选择轻松练/完整练；不靠连续签到惩罚推动使用 | 不是声称所有用户都一定喜欢或坚持 |
| 成年人与老年数字技能的系统性综述强调步进指引、适当节奏、结合实际需要。Xu 等（2025） | 从 F/J 起步；只高亮当前的键；拼音、中文日常用语；首页仅显示 4 关 | 老年训练研究不等于对所有中年用户的效应都经过验证 |
| 电脑新手的自我效能受成功完成任务与练习经验影响。Jokisch 等（2017）、计算机训练随机对照试点（2008） | 不限时、错了可以修正、不计失败；完成时强调实际完成的任务 | 一句鼓励不能替代真正有效的反馈和可达成任务 |
| 分散练习有利于许多记忆任务的保持。Cepeda 等（2006） | 已练关卡至少隔 2 天推荐复习；不追求同一关连续刷大量次数 | “两天”是易解释的产品规则，不是论文验证的唯一最佳间隔 |

## 具体设计约束

1. 新手每次默认仅需 6 个按键，拼音/中文默认一行；完整关作为可选项。
2. 错误提示用“在哪里找到正确键、如何改正”，不将打错与失败绑定。
3. 不能诱导用户保持每日连续签到，练过一天就有记录，允许间断。
4. 熟悉的生活化拼音和语句先于速度、英文单词、排行榜；不引入广告、账号和网络依赖。
5. 延迟复习是温和推荐，用户可以通过关卡列表自由选择。
6. 前期测量聚焦：能否独立打开程序、是否理解提示、能否在不求助的情况下完成第一关、是否愿意再次使用。不能仅由自动化测试断言“对成人有效”。
